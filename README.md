# Face Encoder Decoder and Security Playground

The project contains code for trying out 2 mechanisms, **Arc2Face** for a facial recognition and reconstruction-from-template pipeline and **FaceCloak** for a security framework against reconstruction-from-template adversarial attacks. 

(Currently, the FaceCloak part has not been implemented yet due to several reasons. First, the Arc2Face pipeline is not working properly. And second, several key insights remain unexplored regarding FaceCloak. These shall be undertaken in upcoming updates. Contributions are welcome.)

## Directories and Files

- This directory contains the python notebooks version of the code implementations
- `Python_Scripting` directory contains the Arc2Face and FaceCloak Repo, the python scripts to run the implementations and a detailed instruction on how to setup the environment.
